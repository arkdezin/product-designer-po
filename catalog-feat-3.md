# Catalog Maintenance Issue Flagging and Modification

## Description

Provide Internal Teams with a centralized workflow for reviewing, cleaning, correcting and approving syndicated products.

## Benefit Hypothesis

A centralized workflow for internal teams will improve in Data quality score, increase trust on catalog, reduce manual workflow and reduced operational cost

## Acceptance Criteria

- When modifying products, all team members other than Product Review (validation) will have access to this module.
- When accessing the modification screen, the team member should be able to view Raw Data, AI Enriched Data, Live Catalog Data.
- By default all fields will be disabled for any modifications.
- When modifying any field of the product, the user needs to first select the specific field any modify it.
- When the field is modified, it is mandatory to provide a reason for modification before it could be submitted for approval along with the confidence score.
- When the product is send for approval with the modified fields, it will be send to the catalog queue page for review by DM team member.
